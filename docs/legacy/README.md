# 历史资料

本目录保存从 Windows 版本迁移过来的配置记录、排查记录和配图。它们用于追溯旧实现与家庭 WireGuard 测试过程，不是 Ubuntu 26.04 版本的安装或故障排查依据。

当前版本只支持 Ubuntu 26.04 x86_64，不支持 Windows 或 macOS。旧资料中的 PowerShell、Windows 网卡选项、Windows 路径、Windows 服务和旧 HTTP 接口均不适用于本版本；请从仓库根目录的 [`Ubuntu使用说明.md`](../../Ubuntu使用说明.md) 开始。

历史文件可能包含测试时使用的地址、命令或截图。请将其中的 IP、密钥和配置视为示例，使用前重新核对本机环境，不要复制真实私钥或校园网地址到公开仓库。
